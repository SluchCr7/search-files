## 🎯 نظرة عامة على المشروع
يهدف هذا النظام إلى تحديث تجربة البحث في الأرشيف الحكومي والوثائق التاريخية والقانونية. تم استبدال الأشكال القديمة بواجهة مستخدم حديثة وبسيطة، تمكن الباحثين والحقوقيين من الوصول السريع والموثوق للوثائق عبر أدوات بحث بسيطة ومركبة، مع خط زمني خاص بأعداد الجريدة الرسمية ودليل إرشادي تفاعلي.

---

## ✨ المميزات الرئيسية
- 🌐 **دعم كامل للغة العربية (RTL):** تم بناء الواجهة مع الالتزام باتجاه `dir="rtl"` وخط `Cairo` عالي الوضوح من Google Fonts.
- ⚡ **أداء فائق بدون خادم خارجي (Frontend-Only):** يعمل النظام على مصفوفات بيانات وهمية غنية تشمل أكثر من **45 وثيقة تشريعية وتاريخية** و **32 عدداً متسلسلاً للجريدة الرسمية**.
- 🔒 **Type-Safe:** مبني بنسبة 100% باستخدام **TypeScript** مع تعريفات واضحة لجميع الكيانات والعمليات.
- 📱 **تصميم متجاوب بالكامل (Fully Responsive):** يعمل بانسيابية على أجهزة الحاسوب المكتبي، التابلت، والهواتف المحمولة.
- ⭐ **نظام المفضلة والمزامنة المحلية:** إمكانية حفظ الوثائق والوصول إليها عبر التخزين المحلي للمتصفح (`localStorage`).
- 🧭 **شاشة مساعدة متطورة:** لوحة جانبية (Drawer) منزلقة من اليسار توفر دليلاً عملياً، شرحاً للمعاملات المنطقية، وأمثلة جاهزة قابلة للتطبيق بنقرة واحدة.

## 🖥️ شرح الشاشات والوظائف بالتفصيل

### أ) البحث البسيط (Simple Search)
- **اختيار قواعد البيانات (Multi-Select Chips):**
  تضم الشاشة **14 قاعدة بيانات أرشيفية متخصصة**:
  1. وثائق حكومية
  2. الاتفاقيات الثقافية
  3. عدد الجريدة الرسمية
  4. عدد ممتاز
  5. ملحق جريدة رسمية
  6. اعلانات الشركات
  7. علامات تجارية
  8. مذكرات مجلس الأمة
  9. ملحق مذكرات مجلس الأمة
  10. خطابات الملك عبد الله الثاني ابن الحسين
  11. خطابات جلالة الملك الحسين بن طلال
  12. خطابات سمو الأمير الحسن بن طلال
  13. الوثائق الخاصة
  14. أرشيف الصور
- **أزرار التحكم الجماعي:** زر "تحديد الكل" وزر "إلغاء التحديد" مع عداد حي للشرائح المحددة.
- **شرط التحقق الذكي (Validation Rule):**
  - **زر البحث معطل تلقائياً (`disabled`)** طالما لم يتم تحديد قاعدة بيانات واحدة على الأقل.
  - ظهور تنبيه نصي إرشادي لتوجيه المستخدم.
- **حقل البحث المتقدم:** حقل إدخال واسع يدعم البحث الفوري بالكلمة، الموضوع، أو رقم الوثيقة مع زر مسح سريع.

---

### ب) البحث المتقدم (Advanced Search)
شاشة مخصصة لبناء استعلامات بحث معقدة ودقيقة:
1. **تفعيل الحقول المشروط:**
   - تكون حقول "إسم الحقل"، "معيار البحث"، "كلمة البحث"، "إلى قيمة"، و"النطاق الزمني" **معطلة افتراضياً** ولا تتفعل إلا بعد قيام الباحث باختيار "قاعدة البيانات" أولاً.
2. **معايير المطابقة:**
   - **يحتوي على:** للمطابقة الجزئية للنصوص.
   - **يساوي تماماً:** للمطابقة التامة مثل أرقام القرارات.
   - **يبدأ بـ:** للبحث بمقدمة الكلمات.
   - **ينتهي بـ:** للبحث بنهايات الأسماء والشركات.
3. **أدوات التحكم المنطقي والترتيب:**
   - محول معاملات منطقية: `و (AND)` | `أو (OR)` | `ليس (NOT)`.
   - مفتاح تبديل (Toggle) لتفعيل الترتيب التصاعدي.
4. **جدول الشروط المضافة:**
   - جدول تفاعلي برأس بلون `--accent` يوثق الشروط المضافة.
   - حالة فارغة واضحة بأيقونة توضيحية عند عدم وجود شروط.
   - إمكانية حذف أي شرط بضغطة زر واحدة.

---

### ج) أعداد الجريدة الرسمية المتسلسلة (Official Gazette Timeline)
متطلب بحثي خاص للباحثين القانونيين لتتبع التسلسل التاريخي للقوانين:
- **ترتيب تصاعدي افتراضي:** يتم عرض الأعداد تلقائياً **من الأقدم إلى الأحدث** (بدءاً من العدد 4800 لعام 2005 وصولاً إلى أحدث أعداد عام 2024).
- **خط زمني عمودي (Vertical Timeline):** خط رأسي يربط الأعداد بعقد دائرية وفواصل زمنية بارزة لكل سنة مع عداد الأعداد المتوفرة فيها.
- **شريط القفز السريع للسنوات (Year Jump Bar):** شريط أزرار علوي يمكن الباحث من التمرير السلس والقفز فوراً إلى سنة محددة (مثل: 2005، 2010، 2015، 2024).
- **إمكانية عكس الترتيب:** مفتاح تبديل اختياري يتيح التبديل إلى "الأحدث أولاً" عند الرغبة مع بقاء الافتراضي "الأقدم أولاً".
- **تحميل تدريجي للأعداد:** زر "عرض المزيد من الأعداد" لتحميل أعداد إضافية بانسيابية.

### د) شاشة نتائج البحث والترقيم (Search Results & Pagination)
- **شريط المعايير المطبقة:** عرض الفلاتر النشطة كـ Tags قابلة للحذف بضغطة واحدة لإلغاء أي شرط وإعادة تصفية النتائج فوراً.
- **بطاقات النتائج الذكية:**
  - عرض اسم قاعدة البيانات ورقم الوثيقة وتاريخ الإصدار وعدد الصفحات.
  - **تظليل الكلمات المطابقة (`<mark>`):** تظليل الكلمة المبحوث عنها داخل العنوان والمقتطف النصي باللون الأصفر الهادئ.
  - أزرار الإجراءات السريعة: "عرض الوثيقة"، "تحميل PDF"، و"حفظ في المفضلة".
- **الفرز والترقيم:**
  - الفرز حسب: الأكثر صلة، الأحدث تاريخاً، والأقدم تاريخاً.
  - شريط ترقيم صفحات متكامل (Pagination) مع أزرار السابق والتالي وأرقام الصفحات.

### هـ) شاشة مساعدة الباحث (Researcher Help Drawer)
لوحة جانبية احترافية تنزلق من الجهة اليسرى للشاشة، وتفتح عبر **الزر العائم الدائم (`؟ مساعدة الباحث`)** أسفل الشاشة أو زر المساعدة في الهيدر، وتحتوي على:
1. **دليل سريع:** 4 خطوات مرقمة وموجزة لكيفية استخراج الوثيقة بكفاءة.
2. **شرح معايير البحث والروابط المنطقية:** جدول تفصيلي يوضح الفرق بين (يحتوي، يساوي، يبدأ بـ، ينتهي بـ) وروابط (AND, OR, NOT) بأمثلة عملية من القوانين.
3. **نصائح ذهبية للباحث:** إرشادات حول تجريد الكلمات والتعامل مع الهمزات وتضييق النطاق بالسنة.
4. **أمثلة بحث جاهزة:** بطاقات لأمثلة استعلامات شائعة (مثل اتفاقيات التبادل الثقافي، قانون الشركات، خطابات العرش)، **عند النقر على أي مثال يتم ملء الحقول تلقائياً وتنفيذ البحث فوراً**.
5. **الأسئلة الشائعة (FAQ Accordion):** قائمة منسدلة بأهم الأسئلة حول تحميل الملفات وحفظ المفضلات والفرق بين أنماط البحث.

### و) الجولة التعريفية التفاعلية (Interactive Tour)
- تبدأ عبر زر "ابدأ الجولة التعريفية التفاعلية" داخل لوحة المساعدة.
- تقوم بتسليط ضوء مرئي (Spotlight Overlay) على عناصر الواجهة الرئيسية بالتتابع (التبويبات، شرائح قواعد البيانات، حقل البحث، بطاقات النتائج، وزر المساعدة) مع بطاقة إرشادية وأزرار "التالي" و"السابق" و"إنهاء".

---

### ز) معاينة الوثائق والمفضلة (Preview & Favorites)
- **نافذة المعاينة الكاملة (Document Modal):** نافذة منبثقة تستعرض شبكة الميتا الرسمية (رقم الوثيقة، تاريخ النشر، عدد الصفحات)، ديباجة النص الرسمي، النص التشريعي الكامل، مع زري "طباعة الوثيقة" و"تحميل PDF".
- **نافذة إدارة المفضلة (Favorites Modal):** تستعرض كافة الوثائق التي قام الباحث بحفظها مع إمكانية عرضها مباشرة أو حذفها أو تفريغ المفضلة بالكامل، ومزامنتها محلياً.

## 🚀 طريقة التثبيت والتشغيل (Getting Started)

### تشغيل مشروع Next.js:

1. افتح موجه الأوامر (Terminal) في مجلد المشروع:
   ```bash
   cd front
   ```

2. قم بتثبيت الحزم (إن لم تكن مثبتة):
   ```bash
   npm install
   ```

3. شغّل خادم التطوير المحلي:
   ```bash
   npm run dev
   ```

4. افتح المتصفح على:
   ```text
   http://localhost:3000
   ```

5. لبناء نسخة الإنتاج (Production Build):
   ```bash
   npm run build
   npm run start
   ```

## 🔌 خارطة طريق الربط بالـ Backend

عند تجهيز الـ Backend والـ APIs، يتم استبدال استدعاءات البيانات المحلية في [`front/data/mockData.ts`](file:///d:/Final%20Projects/search_files/front/data/mockData.ts) بنقاط النهاية التالية:

1. **جلب قواعد البيانات وإحصائياتها:**
   - `GET /api/v1/databases`
2. **البحث البسيط والفلترة:**
   - `GET /api/v1/search/simple?q={query}&databases={db1,db2}&sort={sort}&page={page}`
3. **البحث المتقدم متعدد الشروط:**
   - `POST /api/v1/search/advanced` (مع تمرير مصفوفة `conditions` لإنشاء استعلامات مركبّة).
4. **أرشيف أعداد الجريدة الرسمية:**
   - `GET /api/v1/gazette/issues?order=asc&year={year}`
5. **جلب تفاصيل الوثيقة وتحميل الـ PDF:**
   - `GET /api/v1/documents/{id}`
   - `GET /api/v1/documents/{id}/download`
6. **مزامنة مفضلة الباحث مع حسابه السحابي:**
   - `GET / POST / DELETE /api/v1/user/favorites`
